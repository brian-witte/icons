# icons

Public images that other services load by URL, such as Google Chat app avatars.

| File | Use |
|---|---|
| `google-chat/camber.png` | Camber's Google Chat app avatar (512×512; same image as `camber/camber-512.png`, kept at this path for the Chat config) |
| `helm/helm.png` | Helm app avatar, square full-bleed (1024×1024; safe for circle crops) |
| `helm/helm-512.png` | Same, 512×512 (lighter) |
| `helm/helm-circle.png` | Helm avatar cut to a circle, transparent corners (1024×1024) |
| `helm/helm-circle-512.png` | Same, 512×512 |
| `nexus/nexus.png` | Nexus avatar, square (1024×1024; safe for circle crops) |
| `nexus/nexus-512.png` | Same, 512×512 |
| `nexus/nexus-circle.png` | Nexus avatar cut to a circle, transparent corners (1024×1024) |
| `nexus/nexus-circle-512.png` | Same, 512×512 |
| `camber/camber.png` | Camber avatar, square (1024×1024; safe for circle crops) |
| `camber/camber-512.png` | Same, 512×512 |
| `camber/camber-circle.png` | Camber avatar cut to a circle, transparent corners (1024×1024) |
| `camber/camber-circle-512.png` | Same, 512×512 |

Direct link format: `https://raw.githubusercontent.com/brian-witte/icons/main/<path>`
